# User Interface Delivery

Optimize the user's task before visual decoration.

## Workflow

1. Identify the primary task, user, frequency, input, result, failure states, supported devices, and accessibility needs.
2. Minimize interactions and context changes. When one form, one deliberate action, and an immediate result can complete the task safely, use that flow.
3. Use multiple steps only for genuine conditional complexity, long save-and-resume work, required disclosure, or review of a high-impact action.
4. Show applicable loading, empty, validation, success, error, offline, stale, and permission-denied states without losing valid input.
5. Follow the existing design system and platform conventions. Use restrained hierarchy, readable typography, consistent spacing, familiar controls, and task-appropriate density.
6. Meet WCAG 2.2 AA for web interfaces and equivalent platform guidance for native or hybrid mobile behavior.
7. Verify the critical flow visually and interactively at supported sizes, with keyboard and appropriate assistive technology in addition to automated checks.

Read [the interaction reference](references/interaction.md) for forms, mobile, extensions, or localized interfaces.
